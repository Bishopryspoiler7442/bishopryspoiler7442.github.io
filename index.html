ilo3-irc is a specialized application that lets you connect to HP iLO 3 and iLO 4 management controllers from your Mac. It's designed specifically for Apple Silicon (M1, M2, M3) Macs and provides a full keyboard, video, and mouse (KVM) experience - essentially giving you a virtual monitor into your server's console.

🔍 What is iLO and Why Do You Need This?

HP iLO (Integrated Lights-Out) is a built-in management processor on HP servers. It provides remote management capabilities, including the ability to view and control the server's display, keyboard, and mouse - like sitting in front of the machine, but from anywhere.

Previously, accessing iLO 3 and iLO 4 consoles required Java browser plugins or special software that didn't work well - or at all - on newer Apple Silicon Macs. ilo3-irc solves this entirely.

This client eliminates the need for WebStart, Java browser plugins, Windows emulators, or Rosetta translation. Everything runs natively on your Mac's ARM64 architecture, providing a smooth and reliable experience.

📖 User Guide

Your First Connection

When you launch ilo3-irc, you'll see a controller registry showing all the servers you've previously connected to. To add a new server:

  1. Enter the IP address or hostname of your HP iLO interface
  2. Provide your iLO username and password
  3. Click "Connect"

Inside the Remote Console

Once connected, you'll see your server's display. You can:

  • Use your mouse and keyboard to control the server normally
  • Access virtual media features to mount ISO images or USB drives
  • Power on, restart, or gracefully shut down the server
  • View server health and sensor status

Managing Multiple Servers

You can save multiple server configurations in the controller registry. Each server is listed with its unique fingerprint for your security. Simply double-click any saved server to reconnect instantly.

🔧 Troubleshooting

✅ Problem: Application won't open
Solution: Try right-clicking the application and selecting "Open" from the context menu. If this doesn't work, check if your Mac's security settings are blocking the app (System Settings > Privacy & Security > Security).

✅ Problem: Can't connect to server
Solution: Verify that the server is reachable (try pinging it). Ensure the iLO management port (usually 443) is open and accessible from your network.

✅ Problem: Connection is slow
Solution: Check your network speed. For better performance, reduce the remote console resolution or frame rate in the display settings.
